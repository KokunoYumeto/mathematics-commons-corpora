# Agent operating contract

After compaction, restart, or uncertainty, treat summaries as untrusted
locators. Before any mutation, reread `README.md`, `RIGHTS.md`, the complete
registry, `git status`, the current branch, remotes, and the latest accepted
release manifest.

This repository owns control metadata only. It never owns upstream source or
mutable translation payload. Append or supersede decisions; do not silently
rewrite adverse evidence. Never publish content while its rights state is not
affirmatively distributable. Record exact commits, trees, hashes, and access
times. One task may write only its explicitly assigned namespace.
